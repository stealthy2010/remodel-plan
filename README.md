# Remodel plan: 13295 S Old Knik Harbor Dr

Interactive 3D model of the house and the planned remodel. Open it here:

**https://stealthy2010.github.io/remodel-plan/**

- `index.html` – remodel plan with a Current / Remodel switch
- `current.html` – the house as it is today (https://stealthy2010.github.io/remodel-plan/current.html)

Drag to look around, scroll or pinch to zoom. Use the buttons at the bottom to switch between the outside, the main floor and the upper floor.
